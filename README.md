## 💻 How to Compile and Run
Ensure you have a C/C++ compiler installed (like `gcc` or `g++`).

### For C Files:
```bash
gcc filename.c -o program
./program
```

### For C++ Files:
```bash
g++ -std=c++17 filename.cpp -o program
./program
```
